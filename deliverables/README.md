# Operation Cyber Storm — Docker Build Guide
# CTFd Registry: registry.ctfd.io/<your-org>/<image-name>

## Build Order
Build in this order to respect dependencies:

1. container1-splunk       (heaviest build — pre-indexes logs, ~15-20 min)
2. container2-webapp       (medium — installs PHP, sqlite, steghide; embeds stego at build)
3. container3-nginx-static (fast — pure static files)
4. container4-flask        (fast — minimal Python)
5. container5-ubuntu-ssh   (fast — Ubuntu + SSH + pre-loaded files)
6. container67-kali        (heavy — full Kali toolset, ~20-30 min)
7. container8-privesc      (fast — Ubuntu + SSH + sudo config)
8. container9-phishing     (fastest — single static HTML file)

## One-at-a-time Build + Push Commands
# Replace <your-org> with your CTFd org name (found in registry.ctfd.io URL)
ORG="<your-org>"

docker login registry.ctfd.io

docker build -t registry.ctfd.io/$ORG/cs-splunk        ./container1-splunk/
docker push registry.ctfd.io/$ORG/cs-splunk

docker build -t registry.ctfd.io/$ORG/cs-webapp        ./container2-webapp/
docker push registry.ctfd.io/$ORG/cs-webapp

docker build -t registry.ctfd.io/$ORG/cs-nginx-combined ./container3-nginx-combined/
docker push registry.ctfd.io/$ORG/cs-nginx-combined
# Serves BOTH Recruit Stage 1 (/) AND Recruit Stage 7 (/webmail/)
